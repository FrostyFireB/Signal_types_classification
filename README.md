# Signal Types Classification

## О проекте

Цель работы - автоматически разделить 23 479 сигналов на три кластера:

- два кластера, соответствующие двум основным типам сигналов (гамма-кванты и нейтроны),
- третий кластер - аномальные, смешанные или неоднозначные сигналы.

Задача решается методами машинного обучения без учителя с последующей интерпретацией полученных кластеров.

Соревнование Kaggle:  
https://www.kaggle.com/competitions/signal-types-classification

Метрика соревнования: accuracy.

## EDA и предобработка

В ходе EDA были изучены:

- размер и структура датасета,
- наличие пропусков,
- служебные признаки,
- примеры исходных сигналов,
- положение максимума импульса,
- амплитуда и интеграл сигнала,
- ширина импульса,
- различия формы сигналов.

Для каждого сигнала оценивается baseline (базовая линия) по области до основного импульса.

После этого исходный сигнал преобразуется относительно baseline:

```python
pulse = baseline - signal
```

Это позволяет анализировать форму импульса независимо от абсолютного уровня исходного ADC-сигнала.

---

## Feature Engineering

Основной акцент сделан не только на амплитуде, но и на форме импульса.

Для каждого сигнала рассчитываются, в частности:

- положение максимума,
- максимальная амплитуда,
- площадь импульса,
- логарифм площади,
- ширина на половине максимума,
- площадь поздней части сигнала,
- отношение площади хвоста к полной площади сигнала.

Ключевой признак:

```text
tail / total
```

Он показывает, какая доля общей площади импульса приходится на его позднюю часть.

Начало хвостового окна не задаётся вручную: оно подбирается автоматически по качеству разделения двух компонент Gaussian Mixture Model.

## Сравнение моделей

В ходе работы были проверены несколько алгоритмов кластеризации:

- KMeans,
- MiniBatchKMeans,
- Gaussian Mixture Model с различными типами ковариационной матрицы,
- итоговая условная Gaussian Mixture Model.

Для сравнения использовались внутренние метрики:

- Silhouette Score,
- Calinski-Harabasz Score,
- Davies-Bouldin Score.

При этом внутренние метрики не использовались как единственный критерий выбора модели.

В черновых экспериментах некоторые модели показывали хорошие внутренние метрики, но низкий результат на Kaggle. Это показало, что модель может формировать геометрически компактные кластеры, которые не соответствуют нужному физическому разделению сигналов.

## Финальная модель

Финальный подход основан на двумерной структуре:

```text
энергия сигнала × относительная доля хвостовой части
```

После преобразования данных становятся заметны две основные группы сигналов.

Для их разделения используется условная Gaussian Mixture Model:

1. сигналы делятся на интервалы по энергии,
2. внутри каждого интервала обучается GMM с двумя компонентами,
3. для каждой области находится граница между двумя компонентами,
4. полученные границы сглаживаются,
5. формируется итоговая граница между двумя основными типами сигналов,
6. явно нетипичные сигналы относятся к третьему кластеру.

Такой подход лучше учитывает зависимость формы сигнала от его энергии, чем одна глобальная модель кластеризации.

## Нумерация кластеров

В задаче кластеризации номера кластеров сами по себе не имеют физического смысла.

Например, один и тот же результат может быть получен как:

```text
0 - первый тип
1 - второй тип
```

или наоборот:

```text
0 - второй тип
1 - первый тип
```

Поэтому после построения кластеров выполняется только перенумерация двух основных кластеров: 0 и 1.

То есть объекты не переклассифицируются — меняются только номера двух найденных групп. Кластер 2 остаётся без изменений.

- количество строк,
- наличие двух требуемых колонок,
- уникальность `index`,
- допустимые значения кластеров `0`, `1`, `2`.
